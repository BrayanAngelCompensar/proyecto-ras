## Proyecto

Aplicación web contable para micro y pequeñas empresas con un software base estándar, con opción de personalización a gusto del usuario.

## Módulos de la aplicación

- Contabilidad: su respectivo registro de sus ventas y gastos.
- Financiera: el estado de los resultados obtenidos y el flujo de caja.
- Terceros: una respectiva base de datos para registrar sus clientes y proveedores.
- Cartera: cuentas por cobrar a ciertos clientes y por pagar que serian a sus proveedores.
- Inventario: el respectivo registro de sus productos con su precio y el stock.

## Tecnologías previstas

- Backend: Django
- Frontend: pendiente
- Control de versiones: Git y GitHub
- Gestión de tareas: Azure DevOps

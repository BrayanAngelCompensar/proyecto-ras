# Requisitos Sencillos

## funcionales

- puede hacer su registro y su inicio de sesion como usuario.
- se permite registrar sus ventas o gastos con su respectiva fecha, hora y sobre que es.
- como usuario puede registrar como una base de datos a sus clientes y sus provedores.
- El usuario puede realizar su inventario de sus servicios o productos para mayor facilidad.

## no funcionales

- el mecanismo debe ser facil de entender para los usuarios con pocos conocimientos.
- La información de cada empresa debe estar protegida y privada por las demas empresas.
- La aplicación debe funcionar o tener su respectiva pagina web.
